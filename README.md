# Veda

Ayurvedic, Homeopathy & healthcare e-commerce (Delhi NCR). Next.js 14 (App Router).

**Status:** Phase 0 preview. Sample catalogue in `lib/data.js`, cart saved in browser. No database, login or payments yet.
Full plan: `docs/schema.sql` (database) and `docs/sitemap.md` (pages, APIs, phases).

## Run locally
```
npm install
npm run dev
```

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. vercel.com -> Add New -> Project -> import the repo.
3. Framework is detected as Next.js. Click Deploy (no environment variables needed).
